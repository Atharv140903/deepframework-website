# DeepFramework Website v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the DeepFramework home page from the approved canvas as a statically exported Next.js site and deploy it to the existing Render static site at `https://deepframework.in`.

**Architecture:** Next.js App Router with `output: 'export'` renders every route to HTML at build time into `out/`. A shared root layout (fonts, tokens, Header, Footer, default metadata) wraps pages; the home page is composed from one component per canvas section, each rendering typed copy from `src/content/home.ts`. Two test layers: component tests (Vitest + Testing Library) and build-output tests that parse the exported HTML and compare its text against the canvas source.

**Tech Stack:** Next.js 16.4.x, React 19, TypeScript, CSS Modules, `next/font/google`, pnpm 11, Node 22, Vitest, @testing-library/react, jsdom, node-html-parser.

**Spec:** `docs/superpowers/specs/2026-11-05-website-design.md`

## Global Constraints

- Copy matches `design/home.dc.html` word for word, except the v1 changes: no Contact section, no header "Contact" button, no hero "Get in touch" button.
- No email address, phone number, `mailto:`, `tel:` or `#contact` anywhere in the output.
- Brand voice for any new copy: plain, specific, calm; no hype words, no exclamation marks, no emoji.
- Colour tokens (canvas wins over kit): violet `#2A1B5C`, coral `#FF6B5A`, coral-text `#B8372A`, ink `#151325`, muted/slate `#5A5670`, mist `#F6F4FA`, surface `#FFFFFF`, tint `#EFEBF7`, line `#E1DDEA`, on-violet-muted `#D9D3EE`, night `#120C26`. Names extend the kit's `--df-*` scheme.
- Fonts: Archivo 500/600/800, IBM Plex Sans 400/500/600, IBM Plex Mono 400/500, via `next/font/google`.
- Layout: content max-width 1200 px; side padding `clamp(20px, 5vw, 64px)`; section padding `clamp(48px, 6vw, 80px)` top and bottom; 1 px `line` border between sections; flex rows that wrap (no breakpoints needed).
- Focus ring: 3 px outline, 2 px offset; `#B8372A` on light backgrounds, `#FF6B5A` on the violet band.
- Colour logo only on light backgrounds; white outline logo on dark.
- Site URL from `NEXT_PUBLIC_SITE_URL`, default `https://deepframework.in`. Indexing on.
- Logos, favicons and link-preview image are copied from `../DeepFramework-Design-Kit/`, never redrawn.
- Render service `srv-dbm07459fdbs73be5vpg` auto-deploys every commit on `main`: do not push until Task 7.

## Review Focus

1. **Phone widths below 390 (320–360 px):** nothing scrolls horizontally; the ProjectBrief 4-column timeline stays readable. → Task 6, Step 3 checks 320 px.
2. **Nav from a page other than home (404 now, case studies later):** Solutions/Industries/How we work must go to the home page section, not a missing anchor on the current page. → Task 2 test `header nav links are absolute home anchors`; Task 5 build test on `404.html`.
3. **Unknown URL on the live site:** a visitor gets the branded 404 page with HTTP 404, not Render's default page or a 200. → Task 7, Step 6.
4. **Copy drift during the rebuild:** a typo or dropped sentence in any section. → Task 5 test `section text matches the canvas` (diffs every section against `design/home.dc.html`).
5. **Keyboard users on the violet Technology band:** focus ring must stay visible on dark. → Task 6, Step 4.
